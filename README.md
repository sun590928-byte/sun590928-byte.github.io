# 午月咖啡廳

## 咖啡豆介紹與銷售筆記（`/`）

吧台夥伴的咖啡豆推薦話術手冊（冰釀咖啡・花季濃縮・通用話術）。
以「日沒・靜謐時光」為主題的單頁靜態網站，支援淺／深色主題與行動裝置。

## 營運帳務系統（`/erp/`）

POS 銷售分析、疑似同品項整併、金流與存摺對帳、憑證 AI 歸檔、日記簿／分類帳／試算表／資產負債表／綜合損益表、固定資產折舊、存貨成本、月結檢查、申報行事曆。
使用說明與雲端設定：[`erp/README.md`](erp/README.md)。

## 本機預覽
直接用瀏覽器開啟 `index.html` 即可；ERP 使用 ES modules，請以本機伺服器開啟，例如 `npx serve .` 後前往 `/erp/`。

## 部署
透過 GitHub Pages 發佈（Settings → Pages → Deploy from branch → main / root）。
